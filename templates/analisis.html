¿Cómo funciona el análisis?

Etapas utilizadas para clasificar las reseñas.

1. Entrada de texto

El usuario escribe una reseña cinematográfica.

2. Vectorización TF-IDF

El texto se transforma en valores numéricos para que el algoritmo pueda procesarlo.

3. Regresión Logística

El modelo clasifica la reseña como positiva o negativa.

4. Resultado

Se presenta el sentimiento identificado y las probabilidades de cada clase.
